How It Works

1

Upload Base Ratesheet

Upload your master ratesheet containing all product tabs with base pricing grids.

2

Define Tier Deltas

Set pricing adjustments per tab for each tier. Positive values improve pricing, negative values worsen it.

3

Generate & Download

Generate adjusted ratesheets instantly. Each tier gets its own file with the deltas applied to the base pricing.

Delta File Format

You can import deltas from an Excel file. Supports multiple formats:

Tab Tier Adjustment
DSCR1 2 -0.25
DSCR2 2 0.75
DSCR1 3 -0.50
DSCR2 3 0.50

Column headers can be: Tab/Sheet/Product, Tier, Adjustment/Delta/Adj
